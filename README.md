# Rock Paper Scissors Game

This Python project is a simple and fun terminal-based version of the classic **Rock, Paper, Scissors** game. The game is played between the user and the computer, and the first to win two rounds wins the match.

## 🎮 Game Rules

- **Rock** beats **Scissors**
- **Scissors** beats **Paper**
- **Paper** beats **Rock**
- The game is played in rounds, and the first to 2 victories wins the game.

## 🛠️ Features

- User-friendly text-based interface
- Invalid input handling
- Random computer choice each round
- Option to replay the game after each match
- Computer randomly decides whether to continue after each game
